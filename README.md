# Matchday Odds Arena

Build a professional, fully responsive online sportsbook inspired by the functionality and user experience of Bet360 and other major sportsbook platforms based on the attached master prompt specification:

1. Platform & UI Architecture:
- Desktop 3-column layout: Left sidebar (sports, top leagues, in-play filters), Center (live and upcoming match listings, odds buttons, market tabs), Right sidebar (interactive bet slip).
- Mobile layout: responsive header, sticky bottom navigation, collapsible bet slip drawer.
- Styling: Premium dark navy and charcoal theme with high-contrast accent highlights, crisp typography, clean odds badges.

2. Core Features:
- Football match cards with real-world fixture feel, live match minute/score indicators, and prematch/in-play market toggles.
- Dynamic bet slip supporting Single and Accumulator/Combo bets, live odds selection, stake input, potential payout calculation, and place bet flow.
- User wallet UI showing balance, deposit requests with bank transfer payment slip upload flow, withdrawal requests, and transaction history.
- Admin portal view for managing match statuses, setting odds, and reviewing deposit/withdrawal verification requests.
- Responsible gambling disclaimers and session controls.

Implement with a robust, production-ready structure and modern UI components.
